# Тесты

Запуск: `make test` из корня репозитория, либо `tests/run.sh [фильтр]`.

Всё офлайн: ни сеть, ни роутер не нужны. Дерево upstream zapret2 и «бинарники»
под mips/aarch64 генерятся фикстурами из `lib.sh`, а upstream
`init.d/sysv/functions` подменяется стабом, который пишет вызовы в лог вместо
того, чтобы трогать настоящий netfilter.

Состав набора и что чем покрыто — в разделе «Тесты» корневого README.

## Как добавить тест

Файл `t/NNN-имя.sh`:

```sh
#!/bin/sh
. "$(dirname "$0")/../lib.sh"

assert_eq "ожидаемое" "полученное" "что проверяем"
finish
```

Помощники из `lib.sh`: `assert_eq`, `assert_ne`, `assert_file`, `assert_nofile`,
`assert_grep`, `assert_nogrep`, `assert_count`, `assert_status`, плюс фикстуры
`make_stub_elf`, `make_fake_upstream`, `make_init_sandbox`, `init_run`.

Тест — обычный shell-скрипт, запускаемый отдельным процессом; `finish` отдаёт
ненулевой код, если хоть один случай упал.

## Шаблоны, которых стоит держаться

* Шаблоны grep по логу вызовов якорить: `'^apply_firewall$'`, иначе он поймает
  и `unapply_firewall`.
* Регрессионный тест на найденный дефект проверять мутацией: вернуть дефект и
  убедиться, что падает ровно нужный случай.
